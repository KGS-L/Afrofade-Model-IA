# Story 13.7

Build `/discover` as the public list-first marketplace search experience. Location permission is optional and benefit-explained; city is the manual fallback. Search context preserves `style`, query and provider type in the URL. Results distinguish salons from independent professionals and never require authentication.

A map is intentionally not a release blocker. Empty/degraded states remain useful and direct users to styles/Try-On instead of failing silently.
